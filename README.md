# ilyOS

## ¿Qué es ilyOS?

ilyOS no es un Windows químicamente limpio. ilyOS es la configuración que uso a diario, empaquetada en un playbook de AME Wizard y lista para aplicar.
Este *OS* busca tanto velocidad **como** ligereza, sin dejar de tener en cuenta el minimalismo y la comodidad del uso.

La idea es simple: cada cambio del playbook viene de cómo yo trabajo con el sistema a diario, es decir, decisiones basadas en el uso real, no en la lista de cosas que se podrían desactivar por el mero hecho de hacerlo.

## Filosofía
ilyOS sigue la simple filosofía de tener un equipo configurado y basado en las interfaces y formas de trabajar que he desarrollado a lo largo de los años usando Windows.
Al igual que Omarchy (config. de Arch Linux), este playbook busca generar un entorno a mi gusto (y espero que el vuestro): configuraciones de aplicaciones, barra de tareas, interfaz y demás apartados que he ido modificando, corrigiendo y ajustando.

No busca ser competencia de nadie ni intentar ser el mejor playbook del mercado; si te gustan sistemas como AtlasOS o ReviOS, siéntete libre de usarlos sin problemas, porque son proyectazos más dedicados que los míos.
La idea de este playbook es terminar el proyecto que empecé con 16 años y que retomé con 20, pero dándole el enfoque de usar playbooks, a diferencia de las versiones antiguas de ilyOS, que modificaban la ISO de Windows 10/11 directamente.
Si 5 personas usan este sistema y les mola, me doy por satisfecho; si lo usan mis amigos, me doy por satisfecho; y si lo uso yo, me doy por satisfecho, porque así no tengo que configurar mi equipo en cada formateo anual.

## Requisitos
- Versión más reciente de Windows 11 (actualmente, la 25H2).
- Playbook oficial de ilyOS (por favor, nunca descargues una versión fuera de mis enlaces de descarga).
- [AME Wizard](https://ameliorated.io) - Aplicación que ejecuta el playbook.

## Instalación
1. Descarga la release más reciente del playbook (`ilyOSvX.X.X.apbx`).
2. Descarga y abre [AME Wizard](https://ameliorated.io).
3. Arrastra el playbook a la ventana, ejecuta, sigue las instrucciones de instalación y listo.
